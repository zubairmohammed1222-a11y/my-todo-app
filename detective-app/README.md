# Detective Investigation Web App

An immersive web application that puts users in the shoes of a detective solving art theft mysteries. Built with modern web technologies featuring a dark, polished interface designed to evoke the atmosphere of a classic detective investigation.

## Features

- **Interactive Evidence Collection**: Analyze clues and gather information about the case
- **Suspect Interviews**: Interview potential suspects and uncover new information
- **Case Timeline**: View and analyze the sequence of events
- **Note-taking System**: Record your observations and theories
- **Progress Tracking**: Monitor your investigation progress
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## Technology Stack

- **HTML5**: Semantic markup for structure
- **CSS3**: Modern styling with custom properties and animations
- **JavaScript**: Interactive functionality and state management
- **Font Awesome**: Icon library for visual elements
- **Google Fonts**: Typography for a polished look

## How to Use

1. Open the `index.html` file in a web browser
2. Review the case overview to understand the mystery
3. Navigate through different tabs to:
   - Analyze evidence clues
   - Interview suspects
   - Review the timeline of events
   - Take notes about your investigation
4. Track your progress as you uncover more information
5. Solve the case by piecing together all the clues
